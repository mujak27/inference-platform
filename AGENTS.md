# Agent skills

## Issue tracker

Track issues and specs in this repository's remote GitHub Issues, not local
Markdown tickets. Before creating, updating, or resolving tickets, read
`docs/agents/issue-tracker.md`.

## Triage labels

Use the five canonical triage labels. Before triaging or marking a ticket ready,
read `docs/agents/triage-labels.md`.

## Domain docs

This repository uses a single-context domain documentation layout. Before
exploring terminology or changing an architectural decision, read
`docs/agents/domain.md` and the relevant existing domain documents.
